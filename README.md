# MiniERP

Full-Stack-Portfolio-Anwendung zur technischen Konfiguration,
Auftragsbearbeitung und Produktionssteuerung eines konfigurierbaren
Industrieprodukts.

## Live Demo

**Anwendung:**  
https://minierp-frontend-82yt.onrender.com

**REST API / Swagger:**  
https://minierp-50kg.onrender.com/swagger-ui/index.html

> Hinweis: Die Demo läuft auf einem kostenlosen Cloud-Tarif.
> Nach längerer Inaktivität kann der erste Backend-Aufruf etwas länger dauern.

## Technologie-Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA / Hibernate
- Bean Validation
- Flyway
- PostgreSQL
- REST / OpenAPI / Swagger
- Maven
- JUnit

### Frontend
- Vue 3
- TypeScript
- Vite
- Vue Router

### DevOps
- Git / GitLab / GitHub
- GitLab CI/CD
- Docker / Docker Compose
- Kubernetes
- Playwright E2E
- Render Cloud Deployment

## Fachlicher Prozess

Kunde  
→ technische Lichtkuppel-Konfiguration  
→ technische Prüfung  
→ Freigabe  
→ Kundenauftrag  
→ Auftragsfreigabe  
→ Produktionsauftrag  
→ Produktion  
→ Abschluss
